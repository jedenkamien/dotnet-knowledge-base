# .NET Knowledge Base

A personal collection of notes covering C#, .NET, Azure, distributed systems and software architecture.

The primary goal of this repository is to consolidate concepts, patterns and practical knowledge frequently encountered during day-to-day engineering work and technical interviews.

_(🚧 Work is in progress. New topics are added and existing content is refined continuously.)_

## What's Inside

Topics covered include:

- C# language features and runtime internals
- Asynchronous programming and concurrency
- Azure services and cloud-native development
- Databases and storage systems
- Software architecture and design patterns
- Distributed systems fundamentals

Example subjects include:

- async/await and SynchronizationContext
- Azure Functions and Service Bus
- Cosmos DB partitioning
- Microservices and DDD
- REST API design

## Philosophy

Most articles aim to answer three questions:

1. How does it work?
2. Why does it work that way?
3. When should it be used (or avoided)?

The focus is on practical understanding rather than memorization.

## Audience

This repository may be useful for:

- .NET developers
- Backend engineers
- Technical interview preparation
- Continuous learning and knowledge refreshment
